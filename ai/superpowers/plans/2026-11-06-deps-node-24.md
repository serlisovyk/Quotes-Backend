# Plan: dependency updates and Node 24 in Docker (MY-222)

Branch `my-222-deps-node-24`. Linear issue MY-222, milestone «Баги и безопасность». No spec: API
behavior does not change.

## Goal

Close the `npm audit --omit=dev` findings (critical `proxy-addr`, high `body-parser` and
`ip-address`, moderate `qs`, `moment`, `uuid`), bring dependencies to their latest versions, and
move both Dockerfiles to the Node version `engines` and CI already use.

## Author's answers (2026-11-06)

- `uuid` through `sequelize`: try `overrides`; if tests or startup break, keep it with a decision
  record.
- dotenv 18 and vitest 5: update if the changelog shows no breakage and tests stay green; otherwise
  defer with a decision record.

## Approach

- `npm audit fix` without `--force`, then `npm update`. The suggested `sequelize@3.30` downgrade is
  wrong and ignored.
- `uuid`: `overrides: { "uuid": "^11.1.1" }`. Chosen over keeping the advisory because Sequelize 6
  calls only `v1` and `v4`, which uuid 11 still exports from its CommonJS build; verified by tests
  and importing `sequelize`. Rejected: downgrading `sequelize`, `npm audit fix --force`.
- dotenv 18 removed `.env.vault`, preloading and tips; the app only uses `import 'dotenv/config'`.
  vitest 5 needs Node >= 22.12 and Vite >= 6.4; its changed defaults (`clearMocks`) do not affect
  the tests. Both updated, nothing deferred.
- Raise the `^` floors of the updated direct dependencies to the versions in the lockfile, so a fresh
  install cannot resolve an older vulnerable minor.
- `express-rate-limit`: `max` → `limit` in `src/app.js`.
- `Dockerfile` and `Dockerfile.dev`: `node:24-alpine`.
- Decisions: `uuid-override` and `docker-node-24`, one record each; the `package-json-choices`
  consequence about Node 20 is settled by the new record, not rewritten.
- Docs: `ai/map.md` Docker images; README names no Node version.

## Verification

- `npm run lint`, `npm run format:check`, `npm test`, `npm audit --omit=dev`, `npm outdated`, and
  `npm ci` on the final lockfile.
- `docker compose config` and `docker compose -f docker-compose.dev.yml config`.
- Release notes read: express 5.3, pg 8.23, express-rate-limit 8.7, dotenv 18, vitest 5.
- Image build, `docker compose -f docker-compose.dev.yml up` with `/health`, and the manual API
  check need Docker. If Docker is not running when the task is done, they are reported as not
  verified.
