# Plans

The archive of task plans: what will change and how it will be verified. A file is
`<YYYY-MM-DD>-<slug>.md`, with the slug of the branch `my-<n>-<slug>`, so the plan, the spec, the
branch and the issue pair up. A plan is written for a non-trivial task and committed together with
its spec, in one commit, before any code (`ai/workflow.md`, step 5). A plan cites the records in
`ai/decisions/`, it does not retell them. Read only the plan of the feature you change.
